# 暗码实验室 · Visual Cryptography Lab

一个可以亲手操作的 **Naor–Shamir (2, 2) 视觉密码学**演示。上传图片或选择内置图案，把秘密拆成两份随机像素图案；单独查看任意一份，再把两份叠加，观察秘密如何显现。

这个项目适合用来讲解密码学中的秘密分享、随机性、信息隐藏和安全性实验。它是教学演示，不是通用文件加密工具。

## 功能

- **内置秘密图案：** 钥匙孔、星星、笑脸和爱心，打开就能开始演示。
- **图片预处理：** 支持 PNG/JPEG、EXIF 方向和透明背景；灰度阈值可调，大图自动缩小。
- **随机份额：** 使用操作系统提供的随机字节生成平衡的 2×2 子像素图案；按一下按钮即可重新抽取。
- **三种视觉视角：** 对照秘密图案、单独的一份份额，以及两份叠加后的结果。
- **实验数据：** 查看信息熵、相邻像素相关性、亮点率差和还原对比度。
- **可分发的实验包：** 下载两份份额和 JSON 实验记录。ZIP 不包含原图或重建图，方便分别传递份额。
- **交互小测：** 用一道快速问题检查是否理解秘密如何显现。

## 本地运行

需要 Python 3.10 或更新版本。

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.venv\Scripts\Activate.ps1
```

macOS / Linux：

```bash
source .venv/bin/activate
```

安装依赖并启动：

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## 方案说明

每个秘密像素被扩展为一个 **2×2 子像素块**，所以输出图像的宽和高分别是原图的两倍（像素数扩大 4 倍）。每个子像素块始终含有两个白点和两个黑点。

- 秘密像素为白：Share 2 使用与 Share 1 相同的子像素图案。重叠时留下两个白点。
- 秘密像素为黑：Share 2 使用相反的子像素图案。重叠时四个位置都为黑。

单份份额对两种秘密像素都呈现相同的平衡图案分布。这个实现从操作系统随机源取字节，并用其低两位选择四种子像素排列。叠加在灰度模型中等价于逐点取最小值。白色秘密像素有一半子像素透光，黑色秘密像素没有子像素透光，因此理想对比度 **α = 0.50**。

统计面板中的熵和相关系数是当前样本的实验观察，不能单独作为安全性证明。图像会在运行应用的 Python 进程中处理，不写入项目文件；如果把应用部署到公网，上传内容会由部署服务器处理。

## 项目结构

```text

```

## 复试展示时可以讨论

1. 为什么单独一份份额不显示秘密？这和随机排列的概率分布有什么关系？
2. 为什么这里的对比度是 0.5？增加每个秘密像素的子像素数会带来什么视觉效果？
3. 如果图片放大到两倍分辨率，内存占用会怎样变化？如何用向量化或分块处理改善性能？
4. 如何扩展到 **k-of-n**、彩色视觉密码学，或者让用户比较不同基矩阵的方案？

参考：Moni Naor and Adi Shamir, “Visual Cryptography,” EUROCRYPT 1994, LNCS 950, pp. 1–12.
